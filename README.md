# Музыкальный инструмент с жестовым управлением

## Функции
1) Определение жестов, осуществляющееся в виде определения 
расстояния до руки пользователя; 
2) Прием управляющий данных, вводимых пользователем в консоли 
компьютера и передаваемых по интерфейсу UART; 
3) Расчет частоты генерируемого звука, исходя из настроек и данных, 
поступающих с датчиков 
4) Генерация звука заданной частоты.
